# Branding assets

Optional local server logo:

```text
owa-labs-logo.webp
```

If the file is not present, `../apply-branding.sh` attempts to download the current OWA Labs logo from the public OWA Labs website repository.

Keeping the image optional prevents Nextcloud AIO itself from depending on a custom Docker image.
